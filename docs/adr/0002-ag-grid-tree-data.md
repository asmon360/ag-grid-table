# ADR 0002: Древовидное отображение через AG Grid

- **Статус:** принято
- **Дата:** 2026-10-28

## Контекст

Интерфейс должен показать плоский массив в виде дерева: строки с детьми раскрываются, у каждой строки есть категория и номер. ID бывают строками и числами, поэтому внутренний ID AG Grid должен однозначно различать эти типы.

## Решение

Использовать Tree Data из AG Grid Enterprise с полем родителя (`tree-data-parent-id-field`). Передавать данные через адаптер `toGridRows`, который добавляет строковые `gridId` и `gridParentId`, сохраняя исходные ID и остальные поля.

Адаптер определяет категорию по наличию детей. Для колонки категории используется групповой renderer AG Grid, чтобы показывать раскрытие узлов. Номер строки вычисляется по текущей позиции строки. Модули client-side row model и tree data регистрируются в `src/main.ts`.

## Последствия

- Иерархия задаётся ID родителя, поэтому исходный массив не требуется вкладывать или предварительно сортировать.
- Префиксы типов в `gridId` не дают смешать числовой ID `1` и строковый ID `'1'`.
- `TreeGrid` зависит от AG Grid Enterprise Tree Data.
- Адаптер отвечает за UI-поля и не меняет записи в `TreeStore`.
